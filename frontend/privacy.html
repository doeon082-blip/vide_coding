← 채산으로 돌아가기

개인정보·기록 안내

채산은 한국체육산업개발의 공식 서비스가 아닌 비공식 안내 서비스입니다. 질문하시는 분의 정보를 가능한 한 적게 다루도록 만들었어요. 아래에 무엇을 기록하고, 무엇을 기록하지 않는지, 질문이 어디로 가는지 적었습니다.

한눈에 보기

  • 질문과 답변의 글은 저장하지 않아요. 이 화면의 대화는 브라우저 안에만 있고, 새로고침하거나 "새 대화"를 누르면 사라져요.
  • 회원가입·로그인·쿠키가 없어요. 이름, 연락처 등을 묻지 않아요.
  • IP 주소 원문도 저장하지 않아요. 하루마다 바뀌는 가명 값으로만 사용자 수를 세어요.
  • 답을 만드는 동안 질문이 외부 AI 서비스로 전송돼요. 아래 "질문이 가는 곳"을 확인하세요.

기록하는 것

기록내용목적보관
처리 기록시각, 처리 결과(답함·모름 등), 질문 갈래, 걸린 시간, AI 호출·토큰 수, 사용한 자료 번호, 질문 글자 수, 가명 처리한 값오류 확인, 속도·사용량 파악, 악용 방지30일 뒤 자동 삭제
일별 집계위 기록을 날짜별로 센 숫자(개인을 구분하는 값 없음)서비스 이용 통계집계만 장기 보관
개방 수요 기록답하지 못한 질문의 주제(월, 사유 코드, 갈래, 자료 번호, 자료에 있는 낱말). 질문 문장은 없음어떤 공개 자료가 더 필요한지 파악원문이 없는 통계로 보관

가명 값은 하루마다 바뀌고 서버 메모리에만 있는 키로 만들어서, 같은 날의 반복 질문 수를 세는 데만 쓸 수 있고 원문이나 다른 날의 기록과 이을 수 없어요.

기록하지 않는 것

  • 질문 원문과 답변 원문
  • IP 주소 원문, 브라우저 정보(헤더), 쿠키, 위치
  • 이름·연락처 등 개인을 알아볼 수 있는 정보

질문이 가는 곳 (국외 이전 안내)

질문에 답하려면 문장을 AI에게 보내야 해요. 서비스에서는 Cloudflare Workers AI(미국 Cloudflare, Inc.가 운영하며 서버가 해외에 있을 수 있어요)로 질문과 찾은 자료의 일부가 전송돼요. 채산 서버는 이 내용을 저장하지 않아요. 사용하는 모델(Google Gemma 4)은 Cloudflare의 모델 안내 페이지에 "데이터를 보관하지 않음(zero data retention)"으로 표시돼 있지만, 전송받은 업체의 실제 처리는 그 업체의 정책을 따르며 채산이 대신 보증할 수는 없어요.

내 컴퓨터에서 직접 실행하는 개발 환경에서는 외부로 전송되지 않아요. 서버 없이 보는 예비 화면(예시 답)은 질문을 어디로도 보내지 않아요.

이렇게 써 주세요

  • 이름, 전화번호, 주민등록번호, 계좌·카드번호, 비밀번호, 인증번호 같은 개인정보와 민감한 정보는 입력하지 마세요.
  • 채산의 답은 틀릴 수 있어요. 중요한 내용은 기관에 직접 확인하세요.
