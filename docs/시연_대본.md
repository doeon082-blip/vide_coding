# 채산 시연 영상 대본 (2~3분)

기획서에 영상 주소가 필요하고 발표심사 예비용이기도 합니다. **실제로 두 번씩 돌려 본 질문만** 골랐고, 불안정한 질문은 미리 계산된 예시 버튼으로 바꿨습니다(2026-11-28 확인).

## 녹화 전 점검 (5분)

1. **서버 켜기** (저장소 루트에서)
   ```bash
   cd backend && uv run --env-file .env uvicorn app.chaesan.local.app:app --host 127.0.0.1 --port 8100 --no-proxy-headers
   ```
   브라우저에서 `http://localhost:8100/`을 열고 질문 하나로 답이 오는지 확인합니다.
2. **오늘 AI 사용량 확인:** Cloudflare 대시보드(AI → Workers AI)에서 오늘 Neurons가 여유 있는지 봅니다(하루 10,000, 리허설을 많이 하면 줄어듦).
3. **화면 정리:** 알림 끄기, 브라우저 확대 100%, 밝은 모드·어두운 모드 중 편한 쪽(둘 다 글자 대비 기준 4.5:1을 통과함). 휴대폰 장면을 넣으려면 같은 와이파이 대신 임시 터널 주소를 휴대폰 브라우저로 열어 화면 녹화합니다.
4. **리허설 2회** 후 녹화. 아래 "예비책"의 문구를 외워 두면 응답이 느려도 당황하지 않습니다.

## 이 질문들을 고른 근거 (실측, 질문당 2회)

| 장면 | 결과 | 안정성 |
|---|---|---|
| 시간대별 입차 합계 | 2/2 같은 24행 | 안정 → 그래도 **예시 카드**로(대기 7~8초 절약) |
| 테니스짱 오타 | 2/2 보정·7,970명 | 안정(약 4초) |
| 한체산은 언제 설립됐어? | **1/2** ("근거를 찾지 못했어요"가 나온 적 있음) | **불안정 → 예시 카드 필수**(저장된 답은 항상 같음) |
| 야구장(모른다) | 2/2 | 안정. 단 한 번 25초가 걸림 |
| 공격 문장 차단 | 2/2 즉시 | 안정 |
| 반려견, 새 소식, 줄임말(올팍) | 각 2/2 | 안정. 여유 장면 후보 |
| 유실물(연결 예정) | 2/2 즉시 | 안정. "연결 예정 목록에 기록"을 보여 주는 장면 후보 |

- **가능하면 정직하게 보여 주세요.** 한 번 실패한 장면을 지우고 이어 붙이기보다, 예시 카드는 "미리 계산한 답"이라는 표시가 화면에 나오므로 그대로 두면 됩니다.

## 예비책

- **응답이 10초 넘게 걸리면:** "AI가 자료를 찾고 계산하는 중이에요. 보통 3~5초인데 가끔 더 걸려요"라고 말하고 기다립니다(최대 30초 정도까지 가능). 진행 단계 표시가 화면에 나옵니다.
- **오류가 나면:** 화면의 **"다시 시도"** 단추를 누릅니다.
- **서버가 완전히 안 되면:** `http://localhost:8100/?offline=1`로 열어 예시 카드만으로 시연합니다(서버·AI 없이 동작).
- **오늘 AI 한도가 찼다면:** "오늘 쓸 수 있는 AI 사용량을 모두 썼어요" 안내가 나옵니다. 같은 예비 모드를 씁니다.

## 심사 질문 대비 (짧은 답)

| 질문 | 답 |
|---|---|
| AI가 틀린 숫자를 말하면? | 숫자는 코드가 계산하고, AI가 쓴 문장 속 숫자를 조회 결과와 대조해 다르면 **숫자를 빼고 근거 표만** 보여 줘요. |
| 근거가 없으면요? | "모른다"고 답하고, 어떤 자료가 필요한지 **주제만** 기록해요. 질문 원문은 저장하지 않아요. |
| 개인정보는요? | 질문·답변 원문과 IP 원문을 저장하지 않아요. 질문은 답을 만드는 동안 Cloudflare Workers AI(해외 서버 포함)로 전송되고, 안내 페이지에 적었어요. |
| 정확도는 얼마나요? | 개발용 20문항을 3회 돌려 자료 선택 95%예요. 문항을 제가 만들어서 시험용보다 쉬울 수 있고, 시험용 60문항 결과는 따로 보고해요. |
| 비용은요? | 무료 플랜 안에서 질문당 약 29 Neurons(추정)로 하루 약 340건이에요. 한도를 넘으면 예시 답으로 안내해요. |
| 한계는요? | 같은 질문의 결과가 가끔 달라지고, 오픈API 27종은 아직 연결 전이며, 자료가 오래된 것이 많아요(배지로 알려 줘요). 자세한 건 [기획서_수치정리.md](기획서_수치정리.md)에 있어요. |
| 해킹은요? | 지시문 방어, SQL 검사(읽기 전용 DB, 실행 2초 제한), 요청·하루 한도, 화면의 안전한 출력 방식이 있고 OWASP 기준 점검을 했어요([보안점검_보고서.md](보안점검_보고서.md)). |

## 영상 설명란에 넣을 것

- 서비스 주소(고정 주소가 생기면), 소스 저장소 주소
- "비공식 서비스이며 한국체육산업개발의 공식 서비스가 아닙니다"
- 사용한 데이터: 공공데이터포털 한국체육산업개발 개방 데이터(출처 표기), 기관 누리집 공개 기록
