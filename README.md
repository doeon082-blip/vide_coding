# 채산 · 한체산 데이터 길라잡이

시민이 말로 물으면 **한국체육산업개발(한체산)의 개방 데이터와 공개 기록**에서 근거를 찾아 **출처와 함께** 답하는 AI 안내 서비스입니다. 근거가 없으면 지어내지 않고 "모른다"고 합니다.

> "채산"은 참가자가 붙인 가칭이며 **기관의 공식 서비스가 아닙니다.** 화면과 모든 답에 "비공식"을 표시합니다. 공모전: 2026 KSPO&Co 공공데이터 활용 경진대회.

## 한눈에 보기

| 원칙 | 어떻게 |
|---|---|
| **숫자는 코드가 계산** | 숫자·날짜·판정은 코드가 만들고, AI는 질문 해석·자료 선택·설명만 합니다. AI가 쓴 문장 속 숫자가 조회 결과에 없으면 숫자를 빼고 표만 보여 줍니다. |
| **모든 답에 출처** | 데이터 이름·번호·실제 기간·주의점을 붙입니다. 자료가 오래됐으면 "1년 넘게 갱신 안 됨"으로 알려 줍니다. |
| **모르면 모른다** | 근거가 없으면 추측하지 않습니다. 답하지 못한 질문은 **주제만** 기록해 기관의 추가 개방 검토 자료로 씁니다(질문 원문은 저장하지 않음). |
| **안전** | 지시문 방어, SQL 검사(읽기 전용 DB, 실행 2초 제한), 요청·하루 한도, 화면의 안전한 출력. OWASP 기준 점검 결과는 [보안점검_보고서](docs/보안점검_보고서.md). |

## 바로 써 보기

**서버 없이 화면만 보기(설치 없음)** — 미리 계산한 예시 답 10개가 동작합니다.

```bash
cd frontend
python3 -m http.server 8000
# 브라우저: http://localhost:8000/?offline=1
```

**전체 서비스 실행** — 원본 데이터 적재와 AI 연결이 필요합니다(아래 [실행](#실행)).

질문 다섯 갈래와 실제로 답하는 질문 예입니다.

| 갈래 | 질문 예 | 근거 | 답하는 방식 |
|---|---|---|---|
| 역사 | 한체산은 언제 설립됐어? | 기관 연혁, 보도자료 | 문서 검색 후 원문 링크 |
| 시설·이용 | 올림픽공원에서 반려견과 함께 입장할 수 있어요? | 자주 묻는 질문 | 문서 검색 후 인용 |
| 소식 | 올림픽공원 새 소식을 알려줘 | 핫뉴스, 보도자료 | 날짜순 검색 |
| 기관 정보 | 한체산 사전정보공표에는 어떤 자료가 있어? | 사전정보공표, 정보목록 | 목록 검색 후 링크 |
| 데이터 | 올림픽공원 주차장에서 2024년 7월 시간대별 입차 합계는? | 파일데이터 30종 | 코드가 계산, 막대 그래프 |

## 작동 방식

```
질문 ─ 보안 검사(지시문 차단) ─ 오타·줄임말 보정(고쳤다고 알려 줌) ─ 후보 데이터 선정(코드)
     ─ 계획(AI: 갈래·자료·SQL·검색어를 JSON으로) ─ SQL 검사·실행 / 문서 검색(코드)
     ─ 설명(AI) ─ 숫자 대조(코드) ─ 답변 카드(출처·기간·배지·근거 표)
```

AI 호출은 질문당 **최대 3번**(코드가 강제)이고, 숫자 대조에 실패하면 숫자를 뺀 대체 답과 근거 표를 보여 줍니다.

## 검사 결과 (숨기지 않습니다)

개발용 질문 20개(데이터에서 난수로 뽑고 정답은 DB로 계산, 오타 5·모른다 3 포함)를 3회 반복했습니다.

| 지표 | Cloudflare Workers AI(서비스용) | 로컬 gemma4:26b(개발용) |
|---|---|---|
| 자료 선택 정확도 | 95% · 95% · 95% | 95% · 95% · 95% |
| 전체 통과 | 19 · 19 · 19 / 20 | 18 · 18 · 19 / 20 |
| 숫자·사실 일치 | 93% | 87~93% |
| 모른다 / 오타 보정 / 잘못 고침 | 3/3 · 5/5 · 0건 | 같음 |
| 질문당 시간 | 평균 2.6~4.7초 | 2~6초 |

- 시험용 60문항은 **한 번만** 돌리고 결과를 보고 코드를 고치지 않습니다(결과는 [기획서_수치정리](docs/기획서_수치정리.md)에 기입 예정).
- **한계:** 문항을 제가 만들어서 시험용보다 쉬울 수 있습니다. 같은 질문의 결과가 실행마다 조금 달라질 수 있고(예: "한체산은 언제 설립됐어?"가 2회 중 1회 못 찾음), 가끔 25~30초가 걸립니다(원인 미확인). 오픈API 27종은 아직 연결 전입니다. 한글로 쓴 수("삼십 명")는 숫자 대조가 읽지 못해 따로 거릅니다.
- 자동 테스트: Python 667개 + 화면 47개(린트·타입·비밀값·색 대비 검사 포함), `pip-audit` 알려진 취약점 없음.

## 실행

원본 데이터(`backend/data/raw/files/<번호>.csv` 30종)는 **저장소에 없습니다.** [공공데이터포털](https://www.data.go.kr)의 한국체육산업개발 파일데이터를 직접 내려받아 넣어야 합니다(번호 목록은 `backend/app/chaesan/ingest/specs.py`). 필요한 도구: Python 3.12+, [uv](https://docs.astral.sh/uv/), 화면 시험에는 Node 22+.

```bash
cd backend
uv sync
uv run python -m app.chaesan.ingest.load     # data/chaesan.sqlite 생성(약 2초)
uv run python -m app.chaesan.ingest.docs     # 문서 색인
uv run python -m app.chaesan.ingest.aliases  # 오타 보정용 사전
uv run python -m app.chaesan.ingest.cards    # 데이터 카드
cp .env.example .env                         # 값을 채운다(아래). .env는 git에 올라가지 않는다
uv run --env-file .env uvicorn app.chaesan.local.app:app --port 8100 --no-proxy-headers
# 브라우저: http://localhost:8100/
```

AI 연결은 둘 중 하나입니다(`.env`의 `LLM_PROVIDER`).
- `workers_ai`: Cloudflare Workers AI(서비스용). `CLOUDFLARE_ACCOUNT_ID`, `CLOUDFLARE_API_TOKEN` 필요(무료 플랜 하루 10,000 Neurons).
- `ollama`: 내 컴퓨터의 Ollama(개발용, `gemma4:26b`).

```bash
cd backend && uv run pytest && uv run ruff check && uv run mypy   # 서버 시험과 양식·타입 검사
cd frontend && npm test                                            # 화면 시험(의존성 설치 없음)
```

## 사용 기록과 개인정보

- 서버는 요청마다 **원문이 없는** 기록만 남깁니다: 시각, 처리 결과, 질문 갈래, 걸린 시간, AI 호출·토큰 수, 사용한 데이터 번호, 질문 글자 수, 가명 값.
- **질문·답변 글과 IP 원문은 저장하지 않습니다.** 반복 질문·사용자 수는 하루마다 바뀌는 가명 값으로만 셉니다. 로그는 30일 뒤 자동 삭제됩니다.
- 서비스에서는 답을 만드는 동안 질문이 Cloudflare Workers AI(해외 서버 포함)로 전송됩니다. 자세한 내용은 화면의 [개인정보 안내](frontend/privacy.html).
- 요약: `cd backend && uv run python -m app.chaesan.local.usage_report --days 7`

## 데이터 출처와 이용 조건

- 한국체육산업개발 개방 파일데이터: 공공데이터포털(출처 표기). 이용허락범위는 데이터마다 다를 수 있어 각 상세 페이지를 확인하세요.
- `15160326` 비정형데이터_생태갤러리: **공공누리 4유형(변경금지)**. 사진은 가공·재배포하지 않고 파일 목록만 사용합니다.
- 연혁은 기관 누리집(2026-11-28 확인)의 공개 페이지를 사람이 저장한 것을 읽습니다. 자동 수집 코드는 없습니다.
- 원본 데이터와 DB 파일, API 키·토큰은 저장소에 올리지 않습니다(테스트가 비밀값과 개인 식별 정보를 검사).
